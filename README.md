# Online Examination Website

A simple exam website made with HTML, CSS, JavaScript and Java.

## Features
- Student login (student1 / 1234)
- Multiple-choice questions
- Countdown timer (3 minutes)
- Automatic result calculation

## How to run
- Double-click `index.html`, or
- Run `javac ExamServer.java`, then `java ExamServer`, and open http://localhost:8080
